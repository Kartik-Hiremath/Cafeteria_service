============================================================
  QUICK START - Cafeteria Booking (Blu-Reserve)
============================================================

1. Backend
   ---------
   cd features
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

   cp .env.example .env   # then edit with your IBM_* values

   uvicorn app.main:app --reload --port 8000

2. Frontend
   ---------
   cd features/Frontend
   npm install
   npm run dev

3. Open
   -----
   http://localhost:3000

4. Login
   ------
   - Real W3ID: IBM SSO
   - Dummy W3ID: Pick manager + employee (emp001–emp010)
